# 技能包验证记录

验证日期：2026-11-11。对象是本技能包、通用制作工具和新起步模板；不把原课程的历史报告当成新模板已经通过的证据。

## 已执行

- **技能格式**：`skill-creator/scripts/quick_validate.py` 通过。Windows 默认 GBK 读取中文时需用 `python -X utf8`；文件本身是 UTF-8。
- **结构与来源**：技能及专题文档相对链接存在，代码块闭合；94 个原课程复制文件与 `SNAPSHOT.json` 的 SHA-256 一致。常见令牌格式扫描未发现匹配；这不是全面安全审计。
- **模板计算**：线长独立期望值、固定引脚、边界夹紧、不同有效答案、指标点评、语义时间映射、随机访问和共享画板测试通过。
- **模板浏览器**：真实拖拽、键盘及焦点、固定引脚、当前帧精确移交、练习反馈、390px布局和随机时刻渲染通过；没有 JavaScript 错误。
- **冷启动试用**：另一智能体仅按 skill 和实际请求在隔离目录创建新项目并操作。发现边界显示/浮点误判及手机 SVG 小字问题，已据此修正评分、点评和外部 HTML 读数。
- **边界回归**：6.03 与 2.99 正确失败且说明高于上界/低于下界；3与6端点通过。真实键盘50次小步移动造成的浮点误差在 `1e-9` 容差内正确通过；6.000001仍失败。科学家复用同一判定。
- **手机可读性**：必需的坐标、宽高、总长、当前cue讲解与模型定义提供SVG外HTML文本，390px下至少14px。缩放电影中的内嵌标注本身仍较小，不能仅靠“无横向溢出”声称所有文字都清楚。
- **实际渲染链路**：Chrome渲染18帧 → 两段语义重定时为22帧 → 合成未变速测试音 → 完整解码，通过。测试是320×180的短烟雾测试，不代表新课1080p长片的视觉验收。
- **负例检查**：错误/重复/错序cue、NaN、时间空洞、字幕越界、本地资源越界、provisional成片时钟、截短音频流/视频流均被拒绝。页面时钟与传入时钟不一致会停止渲染，保留已有输出。
- **本地服务**：Range GET、HEAD、尾部区间与416响应通过；只监听localhost。
- **真实课程兼容性**：通用验证器读取原Placement网站的4个视频及28个VTT通过，说明工具能检查现有真实产物；原MP4不属于技能压缩包。

## 限制与使用范围

本次没有调用在线TTS、重制完整课程或发布仓库。通用脚本不评判发音自然度、翻译质量、音乐听感或教学深度；这些仍需按制作指南另行检查。

可迁移工具已在Windows、Python3.11、本地Chrome与FFmpeg测试；其他操作系统未实测。浏览器/FFmpeg路径可参数化。原课程源码快照里的课程专用脚本保留原环境配置，使用前按快照说明调整。

起步模板明确是32秒无声分镜，尚无真实配音或字幕。未来课程必须替换课程模型、补实测声音与时间轴、运行针对该课的完整验收，不能沿用本记录作为新课通过的依据。

公开仓库的下载包从所提交的新版技能目录重新生成，另做CRC和逐文件哈希核对。包大小、SHA-256与实际文件清单在 [`downloads/vlsi-html-course-studio-skill.manifest.json`](../downloads/vlsi-html-course-studio-skill.manifest.json)；它不包含大型成片或隔离验证工作目录。
