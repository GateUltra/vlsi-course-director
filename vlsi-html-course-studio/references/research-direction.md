# 课程研究与导演设计

在开始新课程、重新构思章节或判断原材料与教学效果是否矛盾时阅读。这里描述的是决策方法；课程长度、章数、角色与美术风格均服从当次任务。

## 从课程的真实问题开始

先定位确切 lesson、lab、作业与实现，不要只读仓库首页。课程编号、目录编号与网页标题可能不同；例如 Placement Lesson 06 实际位于 `module02-05-analytical-place`。建立一份简短来源清单：URL、文件路径、取得日期、commit/hash、作者、材料类型、许可证据及缺失项。保存会影响结论的原始片段或研究快照，最终产品的署名另列。

优先回答以下问题，再写开场文案：

| 要确认的内容 | 它影响的制作决定 |
| --- | --- |
| 学生最终必须会做什么 | 视频主线、实验任务、习题的判定条件 |
| 输入、约束、指标、更新步骤 | 动画里哪些对象能移动、哪些数字需要实时计算 |
| 材料里的“理想目标”与代码实际结果 | 哪些话可以说成观察事实，哪些只是动机 |
| 必需背景和可延后的细节 | 定义先出现的位置、扩展笔记的深度 |
| 作业提交物与评价标准 | 是否需要导出坐标、保留运行参数、解释比较结果 |

使用工具确实读取与运行后，才声称“已检查实现”。不可用的链接、未获取的视频、无法核实的许可应记为缺口，不补写成事实。公开网页可读不等于其全部素材获得再分发许可；保持原作者署名，区分原创叙事、算法事实、改写实现和外部美术。

## 在华丽动画前，先给数学一个可检验的落点

建立纯领域模块：输入状态 → 指标／下一状态，不依赖 DOM、颜色、视频时间。先运行原参考实现，再用适当的独立方式核算关键指标，保留小型 golden fixtures。只把同一函数调用两遍，不算独立核对。

例如可对一个 net 的包围盒手算 `width + height`，对四个 bin 显式计数，验证固定点和点数，再比较完整轨迹。出现“不够漂亮”的真实结果时先研究原因：是否容量不足、参数变化没有单调性、两次比较的约束不同？

Placement 的重要发现不是“密度算法一定让溢出变成零”，而是：六个计数点放在四个容量为一的 bin 中，总溢出至少为二。原程序终态也是二。这个限制本身比虚构一条下降曲线更值得教。

将素材分成三种有标识的内容：

- **真实运行**：轨迹来自参考实现，可逐步重放。
- **设计对照**：为了讲因果关系而构造的状态，明确说明条件和改动。
- **示意图**：表达方向或流程，不应让读者误以为是精确求解或布线路径。

绘图可以对真实状态做视觉插值，但插值中间态不是新的一轮求解器迭代。显示离散步骤标签时保持这个区别。

## 面向第一次学习的大学生

“第一次学”不等于每句话都幼儿化。先讲这个工程问题为什么存在，再定义当前示例需要的术语，然后允许学生读公式、预测结果和解释反例。一个有效的小循环是：

1. 抛出具体矛盾：短连接为什么还不够？
2. 给出能看懂的小模型：点、连接、固定端点、容量。
3. 展示可测量的规则：一次只引入一个指标。
4. 提问并留真正的思考停顿。
5. 通过移动或算法步骤揭示因果，数字随状态变化。
6. 让学生接手同一个状态，做一次有目标的实验。
7. 用解释题检查理解，而不只让学生重复屏幕上的数字。

定义应紧邻第一次使用：例如 `net`、`bin`、`HPWL`、`Width × Height`、颜色含义、坐标轴和固定标记。用动画解释概念中的过程，避免用持续入场的文字替代讲解。专门留一个反例说明模型的边界，例如“内部点移动但极值不变，因此这个 net 的 HPWL 不变”。

## 写可驱动生产的 cue，而不是一篇长散文

按语义动作划分 cue，并给稳定 ID。每个 cue 最少回答四件事：观众此刻的问题、旁白、画面变化、下一步能做什么。不要把 ID 编成当前时间戳；声音一改，秒数会变。

```json
{
  "id": "measure_box",
  "chapter": "03",
  "title": "Width plus height",
  "layout": "net-measure",
  "en": "Add the width and height of the box.",
  "zh": "把包围盒的宽与高相加。",
  "pauseAfter": 0
}
```

另存镜头说明和公式／数据来源，不把所有导演注释塞进需要发送给 TTS 的文字中。翻译以 cue 为单位保持含义相同，允许自然语序和长度差异；画面按所选声音实测时钟重新安排。

句子要适合耳朵：明确动作主体，先报对象再报操作，使用标点和短句处理“先取出 D，再取出 A。把 D 放在 A 上方”这类容易误听的流程。缩写如 `H P W L` 可显式拆读；最终根据生成音频判断，而不是只看书面文稿。

## 一分钟样片应证明生产链

在用户要求完整制作且需要验证风格时，约 45–60 秒通常足以检验方向；不必为每次小改另设批准步骤。样片至少包含真实知识点、因果动画、选定音色、字幕，以及一个能接手当前状态的交互动作。纯静帧美术板或无声录屏无法证明配音和动画协调。

选择最有代表性的难段：如“拥挤 → 预测 → 疏散 → 双指标取舍”，而不是全做片头。可以另用数秒建立芯片／城市类比，但样片主体必须让人学到东西。接受反馈时分别记录知识、节奏、声音、角色、视觉、交互，避免因为换背景而无意改动算法定义。

## 明亮工作室的可迁移设计规则

案例采用暖纸色背景、绿／珊瑚／琥珀／蓝区分概念、深墨色文字，以及小型科学家角色。复用的是视觉语法，不必让下一门课长得一模一样：

- 颜色有稳定语义，并配文字、形状或图例；容量热区不要无解释地像温度图。
- 主图有足够面积展示因果；人物在公式密集时改为头像，提问和总结时才使用全身。
- 动画可包括路径绘制、遮罩、层次阴影、局部放大、计数器、运动弧线和短暂强调。运动只在解释变化或引导视线时承担任务。
- 在具体结论被说出前，关键状态要已经到位，并留出读图时间。不要旁白说“现在是 52”，画面却仍在从 48.5 缓慢增长。
- 以阶段构建精致感，避免整个七分钟处处高强度动态。标题、公式、实物比喻、局部操作和人物停顿形成节奏。

在样片确认后按章节扩展，先形成全部 cue 的低成本预览和接触表，再做全分辨率长片。保留被验证过的可读性和角色约束，最终用真实成片检查字幕、安全区、转场残影及语音断句。
