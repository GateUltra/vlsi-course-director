## 为什么不是一条“算法越来越好”的动画

模型有 A–F 六个点，A=(0,0)、D=(8,8) 固定，六个 net 为 AB、CD、AC、BD、ABCD、EF。`HPWL(net) = maxX−minX + maxY−minY`。2×2 分箱按点计数，包括固定点；坐标 4 的边界归右／上箱。真实单元的宽高、行对齐和重叠合法化不在该模型内。

先展示独立设计、明确标注容量为二的对照：

| 布局 | A / B / C / D / E / F | 总 HPWL | Overflow |
| --- | --- | ---: | ---: |
| Crowded | (0,0)/(1,1)/(1.5,1)/(8,8)/(1,1.5)/(1.5,1.5) | 48.5 | 3 |
| Distributed | (0,0)/(6,1)/(1,6)/(8,8)/(3,3)/(5,5) | 52 | 0 |

这段回答“为什么短线和空间会有取舍”。之后明确切换到原课程容量为一的实验。原始起点是 A(0,0)、B(8,0)、C(0,8)、D(8,8)、E(4,4)、F(0,4)。六次 force 更新、三次 averaging 更新后，再进行十二对 spreading/reconnect，含起点共 34 个状态。

默认权重 0.55 的 HPWL 从 52 变为约 48.121176，overflow 从二到二；部分中间步骤会到三。六个点、总容量四，所以溢出的理论下界已经是二。更强密度权重不保证单调改善；固定点条件不同的低线长不能拿来作公平对比。原算法还可能产生边界外坐标，展示层扩展画布以忠实显示，未偷偷夹紧真实轨迹。

这正是科学家点评与习题最重要的限制：不要把“overflow 2”一律说失败，也不要把“线长下降”一律说已满足容量。

## 实现架构及值得借鉴的文件

| 责任 | 案例文件 | 可复用的思想 |
| --- | --- | --- |
| 数学与状态 | `course/domain.js` | 纯指标、固定点、可复现参考轨迹 |
| 共同画板 | `course/board.js` | 视频与实验共用 SVG；数字来自状态 |
| 语义时钟 | `course/timeline.js` | `stateAt(t, clock, script)` 保留 cue 和归一化进度 |
| 电影画面 | `course/scene.js`, `film-art.js` | 图表、局部说明、人物按 cue 组成 |
| 角色 | `course/scientist-rig.js` | 闭嘴、轻微胡子、双骨 IK、头像／全身模式 |
| 实验与反馈 | `course/lab.js`, `mentor.js` | 精确转入暂停状态，点评和建议先算后说 |
| 习题 | `course/exercises.js` | 五项概念检查＋一个多解实践检查 |
| 播放器 | `course/player.js` | 音色、字幕、速度独立；章节按所选声音跳转 |
| 配音与字幕 | `scripts/make_course_audio.py` | 精确缓存、实测时钟、28 组字幕 |
| 渲染 | `scripts/render_course.py` | Chromium 生成图片帧；按语义片段重排其他声音 |

声画共用不代表 MP4 可直接编辑：编辑的是脚本、领域状态、共享组件和时间轴，再重新导出 MP4。用户在视频任意时刻点击转入实验室时，网站从同一 `stateAt` 函数求出位置、容量、模式和参数，包含正在运动的插值位置，而不只是加载某一章的默认预设。

科学家的说话表情是表达性的小幅胡子运动，没有音素级同步。原始头像来自 j4p4n 的 CC0 图；身体和骨骼为新绘制代码。完整版默认角色运动按 cue progress 驱动，虽然制作数据也保留了声音 RMS envelope。

## 最终交付规模

八章、39 个 cue，主英文脚本约 885 个词。四种音色均实际生成，英文口音包括英国／美国／印度，另有普通话；七种独立字幕为英、中、法、西、德、日、韩。

| 声音 | 实测节目时钟 | MP4 视频流时长（30 fps） |
| --- | ---: | ---: |
| Thomas／英式 | 398.196 s | 398.200 s |
| Guy／美式 | 394.236 s | 394.267 s |
| Prabhat／印度英语 | 463.116 s | 463.133 s |
| Yunxi／普通话 | 415.476 s | 415.500 s |

成片是 1920×1080 H.264／AAC，30 fps。较长的印度英语保留自然声音速度，画面匹配对应语义片段的真实时长；没有为了强求片长一致而全局拉快旁白。

网页包含三个实验模式（容量二的自由对照、指定 net 的 HPWL、容量一的参考轨迹）、六项练习、完整讲稿和学习笔记；有字幕开关、四种声音、倍速、章节跳转和当前画面转入实验。页面字幕移到图像下方，全屏才使用原生字幕，解决密集数字被字幕／控制条遮挡的问题。

制作使用原生 HTML／SVG／JavaScript 作画，Chromium 按时间截图，FFmpeg 编码。没有用 Pillow 逐帧绘制。主画面渲染一次，其余声音在可按归一化进度重用的 cue 区间中重新安排画面长度；若未来增加逐词强调或精确口型，该简化方法必须重新评估。

## 已取得的检查证据与边界

生产记录显示：五个权重、170 个算法状态与归档实现比较，并独立核算指标及固定点；39 个镜头检查；每声音 117 个语义状态比较；四个最终视频全解码；123 个实际重排片段的帧数与累计边界一致，最大 cue 边界误差 30.667 ms，低于一个 30 fps 帧。

浏览器检查覆盖 32 次章节跳转、28 组字幕选择、12 次精确状态转入，以及快速切换声音、倍速／暂停保持、全屏、键盘和移动端。音频头中尾采样与 WAV 母版的零偏移相关性最低为 0.999968，支持导出未产生可测对齐偏移；这不是人工试听结论。五种新增外语字幕没有独立母语人工审校，已在交付中说明。
