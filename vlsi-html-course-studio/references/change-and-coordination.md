# 修改与协作

适用：长片集成、返工、多智能体分工。协作是可选加速方式，不要求每次编辑都启动多名智能体。

## 沿依赖链判断重建范围

```text
定义/算法 → domain + trace → scene + lab + mentor + exercises
旁白/音色/语速 → clip cache → measured clocks → pictures + captions + chapters
视觉组件 → frame render → picture master → voice variants
翻译/断句 → captions → player checks
任意交付文件 → portable package + inventory
```

| 改动 | 跟进 | 通常不必 |
|---|---|---|
| 网页普通说明 | 版式/链接、重打包 | 重录音/影片 |
| 字幕错字/换行 | 受影响字幕组合、实际显示 | 改未变化的音画 |
| 英文一段旁白 | 所有对应英文音色缓存失效、重测时钟、字幕/章节/拼接；语义改变同步翻译 | 重生成未改文本/配置的clip |
| 角色手势/画面布局 | 相关画面/主片重渲，重新匹配声音版，检查实验一致 | 未改旁白就不调在线TTS |
| 算法/评分 | 独立验证、例子轨迹、说出的数字、习题点评；数值改变重录相关话语 | 用新画面数字配旧旁白 |
| 新增配音 | 单独时钟、字幕组合、图像及语义切换 | 按总时长拉伸旧影片 |
| 新增字幕语言 | 术语/数字、每音色时间表、小屏长句 | 重生成全部声音/图像 |

## 可并行工作包

- **模型与实验**：领域函数、独立计算、Board、操作与习题；交付状态契约与异常结果。
- **叙事与画面**：cue布局、过渡、角色与确定性渲染；读共享模型，不私改领域规则。
- **语言与音频**：认可脚本、TTS配置/缓存、实测时钟、字幕与混音；改脚本通知其他消费者。
- **导演/集成**：研究结论、结构节奏、接口、播放器、反馈、合成与交付。
- **独立复核**：给原始材料和任务，从学习者角度操作并核对，不只按作者的结论确认。

声明文件所有权；共享文件先协调。字段/cueID变更通知消费者。子任务报告改动、假设、实际检查、未检项、待集成接口。不要分别建多套近似时间轴/评分器；验证可以独立，以发现共享模型本身的错误。

## 样片验证最大风险

不要只做片头。选择模型定义、因果变化、数字、角色动作、真实声音和实验移交。多语时间轴是风险则加一条长度不同的配音；公式密度是风险则展示公式。

反馈按知识、可读性、声音、节奏、互动归类，先修误解再加装饰。说明重要取舍，如自然配音长度差、字幕下移、胡须微动非伪口型。

接手记录保存：认可版本、最新约束、源版本、文件入口、端口、音色/时钟、已完成输出、正在跑的进程、验收记录、下一依赖、最终包位置。临时机器路径不能变成可复用skill的硬依赖。
