# 网页、验证与交付

适用：将样片扩成完整体验，或验收最终网站。检查按改动范围选取，不要求每次文字修改重跑全部渲染。

## 学习闭环

围绕“观看 → 带入实验 → 预测/操作 → 反馈 → 练习 → 回看”组织。片旁提供章节，下面提供实验/练习，讲稿和笔记支持跳读。小屏图表、标签与字幕不靠浏览器缩放也能读清。

播放器提供音色、独立字幕（含关闭）、倍速、章节、当前章节、明确错误和需要时的下载。用户主动播放；换音色保留意图；转入实验先暂停。

### 字幕放画面下方，全屏用原生轨道

复杂图表下缘的数字容易被原生字幕和控件盖住。可用：

1. 页面内选中轨道 `TextTrack.mode = 'hidden'`，读取 `activeCues`，以 `textContent` 放到画面下方字幕栏。
2. 其余轨道 `disabled`；关闭时隐藏栏。`cuechange`、`seeked`、加载/切源后更新；切源清空旧字幕。
3. 原生视频全屏改为 `showing`、隐藏外部栏；退出恢复。按目标浏览器测试标准事件及必要的 `webkitbeginfullscreen` / `webkitendfullscreen`。
4. 原生 CC 菜单改选时同步自定义选择器，避免两套状态争抢。

事件代码存在不等于所有平台支持。真实浏览器检查全屏，英文/日文/韩文可作长句与分词压力样本；其他语言仍需抽检。

## 实验交互

- 拖动逆变换与图板使用同一坐标映射；不能把响应式 CSS 像素当世界坐标。
- 拖动、键盘和触摸按钮可用，锁定对象可见。重绘 SVG 后恢复选点焦点。
- 拖动中更新数值，结束后比较整次手势前后；不要拿上一 pointermove 当原状态。
- 接收新状态/切模式前停自动步进、清理旧定时器和选点。
- `aria-live='polite'` 简短播报结论，避免每像素重读段落。
- 颜色辅以文字/数字/形状；可暂停/步进，减少非必要运动。

## 验证矩阵

| 层 | 实际行为 | 检查方法 |
|---|---|---|
| 知识 | 定义、边界、锚点、更新顺序、目标与约束 | 独立手算小例、对照归档原实现、边界和不可能目标；不能只让实现比较自己 |
| 时间轴 | 随机访问一致，多音色同cue/progress同状态 | 起中末/倒序抽样、数值状态深比较 |
| 构图 | 字体数字清晰、手势不遮挡、转场清理 | 每类layout和转场前后截图，查看最终压缩帧 |
| 音频 | 音色断句、音量、开尾、BGM可懂度 | 峰值/响度测量加代表段试听；统计不等于听感审校 |
| 成片 | 全部可解码、时长匹配、无累计漂移 | ffprobe、完整decode、整数帧边界；必要时头中尾音频母版对齐 |
| 字幕 | 可加载、顺序/边界、数字完整、不遮挡 | VTT解析、小数48.1/48,1回归、activeCues与实拍截图 |
| 播放器 | 真媒体播放、章节、快切音色保留语义 | 暂停/播放中切、连续快切、字幕倍速保留、错误状态 |
| 移交 | 中间坐标、模式、约束精确匹配 | 每种模式/音色抽样运动中的进度，深比较实际状态 |
| 习题 | 多答案、解释和跳转有效 | 一个错误、两个不同正确样本，锚点/边界反例，实际点击回看/试验 |
| 网页 | 桌面/手机、键盘/触摸/全屏可用 | console/network、约390px无横向溢出、焦点和点击检查 |
| 包装 | 解压独立启动，媒体齐全 | 新目录/新端口启动，ZIP CRC、文件清单、哈希 |

`loadedmetadata` 不等于有声音，VTT存在不等于字幕可见。无法主观试听、真机测试或母语审校时分别报告限制，不把机械验证写成人工评审。

## 本地服务与部署

ES modules、fetch、字幕经 HTTP 使用。`file://` 下 module 可能根本不执行，启动提示放在独立 inline script，不只放 module catch。`serve_site.py` 供 localhost 及 byte ranges；验证200/206、MIME与跳转。

静态网站用相对路径，兼容仓库子目录。启动脚本 cd 到自身目录；写明 Python 仅为本地服务，观看不需要生产期 Playwright/TTS/NumPy。端口占用先识别服务，不盲目关闭其他项目。

交付区分：

1. **可运行网站**：页面/脚本、内容、全部视频/字幕/时钟、来源、启动方式。
2. **可编辑制作项目**：模型、脚本、角色、翻译、TTS配置/缓存、分轨WAV、画面母版、渲染命令和验证记录；可与网站包分开，写清位置。
3. **摘要**：实际章节/时长/语言、入口、下载、源文件、已测与未测。

最后一次修改后重建压缩包。明确网页便携包、制作项目、仅源码示例的区别。

公开发布按用户授权和实际目标仓库进行。push、构建、网页/媒体可访问是不同证据；localhost或building状态不等于上线。许可证据不明确时描述事实，不从“打算用CC BY”推定授权。
