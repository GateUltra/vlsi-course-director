# 可运行的 HTML / SVG 起步模板

当需要新建一个课程项目、检验共享组件技术链，或给下一位制作智能体展示一个最小可运行结构时，使用 `assets/starter/`。这不是 Placement Lesson 06 成片的缩小拷贝，而是原创的两个引脚线长估计案例。

## 创建与预览

在 skill 根目录执行：

```powershell
python scripts/init_course.py --destination "D:\Courses\NewLesson" --title "My VLSI Studio"
Set-Location "D:\Courses\NewLesson"
python serve_site.py --directory . --port 8780
```

另开终端执行 `node check.mjs` 进行计算与时间状态验证。若 skill 未附服务器脚本，可用 Python 标准命令 `python -m http.server 8780 --bind 127.0.0.1` 查看这个无视频模板。真正带视频的课程应使用支持 Range 的服务器。

安装 Python Playwright 后，可额外执行 `python check_browser.py`（或用 `--browser` 指定本机 Chromium 路径）。它会临时开启本机服务器，检查真实拖拽、键盘焦点、精确状态转移、多个有效练习答案、390px 布局及渲染随机访问；`--screenshots NEW_DIRECTORY` 可保留截图。模板不把“代码能解析”当成网页交互已经通过验收。

初始化脚本只接受**不存在的新目录**，不会覆盖项目，也不连接语音服务。网页从 `content/script.json` 读取标题，通过 `textContent` 显示。可直接将 `assets/starter/` 复制到所需位置，但不要修改 skill 内的模板来制作正式课程。

## 模板已有的可验证行为

- `domain.js`：A 固定在 (2, 2)，B 可移动；线长等于 `abs(dx) + abs(dy)`。这是两引脚包围盒 HPWL / 曼哈顿距离的教学代理，不是完整布局或布线求解器。
- `board.js`：`Board(state, options)` 是纯 SVG 视图。影片场景与实验室调用同一个函数；坐标变换也由同一模块导出。
- `timeline.js`：`stateAt(time, clock, script)` 是纯函数，可以先渲染 23.7 秒，再渲染 8 秒，再返回 23.7 秒，得到相同状态。没有依赖前一帧的计数或随机数。
- `scene.js`：明亮纸色场景与原创闭嘴科学家。人物仅为轻量结构示例，不包含完整课程所用的双臂 IK；该高级技术应按人物章节另行实现。
- `app.js`：预览播放、拖动时间轴、按语义章节跳转；“Take this scene into the lab”复制暂停时刻的真实状态，不重置成关键帧。实验室支持拖拽、键盘和按钮微调，A 不可拖动。
- 科学家点评比较操作前后实际线长，候选建议先由模型计算。它没有在线模型依赖，也不把较短线长宣称为最优布局。
- 练习读取当前实验室状态，接受任意板内、固定 A、线长在 3–6（含端点）之间的位置，不要求一个秘密坐标答案。
- 评分使用未舍入数值，显示分数明确标为舍入值。即使 6.03 在画面上显示为 6.0，反馈仍说明“超过 6 的上限”；2.99 同理说明“低于 3 的下限”。边界仅使用 `1e-9` 数值容差处理连续浮点移动误差，例如 50 次减 0.1 后产生的 `6.000000000000009`；这不是把分数四舍五入后评分。
- 手机上缩小的 SVG 标签可能不够清楚，模板另有独立 HTML 读数，实时列出 A/B 坐标、包围盒宽高与总长度；读数、定义、当前 cue 文本在 390px 下至少 14px。不要仅以“无横向溢出”判断移动端教学内容可读。
- `render.html` 暴露 `window.ready`、`window.clock`、`window.script` 和同步 `window.renderAt(seconds)`。`renderAt` 返回实际绘图状态，便于浏览器抽帧与截图验证；默认画布 1920×1080。

## 有意没有提供的内容

这是一段 **32 秒的无声故事板**。`content/demo-clock.json` 明确带 `provisional: true`，秒数是手工预览值。网页与渲染页都标明它不是已经配音的成片。不要将这份时钟提交为真实测量结果，也不要移除提示后把无声预览称作完整课程视频。

制作正式课时应补上经授权的真实 TTS、实测每个语义 cue 的时长、对应配音的图像时间轴、独立字幕、音频混音、播放器和交付检查。字幕、音色和倍速选择器没有在模板里伪造。完整实现可参考配套案例与音频/网页章节。

## 推荐改造顺序

1. 用真实课程资料重建 `domain.js` 及可验证数值，再改 `check.mjs` 的期望；保留“不修改输入快照”等有意义的不变量。
2. 按新学习目标写 `script.json`，用稳定的 `id` 贯穿画面、音频、字幕、实验转移和章节导航。
3. 修改 `stateAt` 与 `Board`，先验证任意时间跳转一致、视频和实验室的坐标完全相同。
4. 制作真实配音样片并替换 provisional clock；一个英语句子不一定适合其他语言逐字拆分，按语义 cue 对齐。
5. 用正式播放器替换预览控制区，加入多语言字幕、voice-specific clocks、语义位置切换和媒体错误提示。
6. 为真正的算法和误区设计练习；替换模板的线长范围目标，保留“根据当前状态评分”和多个有效答案的思想。

视觉模板是一个可替换的实现选择。不要强制所有后续课程都使用两引脚模型、相同配色、32 秒长度或科学家角色。
